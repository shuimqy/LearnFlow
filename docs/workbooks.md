# 课件做题本

入口：课程资料页的“课件做题本”，路径 `/courses/{id}/workbooks`。
页面顶部“选择来源课件”支持多选，同一课程的多个课件可合并到一本。来源与范围同时用于手动选题和自动整理，调整范围不会清空本册已有题目。

## 整理和打印

1. 在“选择来源课件”勾选一份或多份课件；默认全部选中。不选任何课件时停止查找并禁用自动整理，不扩大为全课程。
2. 需要限定时展开“限定章节或页码”，可选择不同课件的章节，或填写页码。页码使用 PDF 物理页码，从 1 开始，同时应用于每份所选课件；章节与页码取交集，范围调整后列表立即更新。列表还可按题目类型、标题关键词进一步筛选。
3. 命名章节分组，选择“勾选后加入分组”，勾选课件中的习题或讲解例题；也可使用“按要求自动整理做题本”生成原题草稿。
4. 调整分组和题目顺序，也可将题目移动到其它分组。编辑题干、答案和解题步骤时支持 Markdown 与 LaTeX。
5. 点击“核对裁片与标签”，在原页上框出完整原题及题图，确认不包含答案和解析后保存。跨页题可追加其它页的区域。
6. 选择文字重排或原题保真，设置答题留白；可选少量、标准、较多或每题另起一页。答案解析可以统一附在末尾，来源页码可以选择打印。
7. 保存后可重新打开；“保存并导出 PDF”先保存当前内容，再按该版本生成 A4 PDF。

每本最多 100 道不同的课件题目、30 个分组；正文总量不超过 30 万字符。
顶部“做题本名称”可直接编辑，已有题本点击“保存名称”单独改名，保留本页尚未保存的题目编辑；新题本随首次保存一起命名。
空分组在保存时移除。无答案或解题步骤的题目明确显示“课件未提供”，不调用模型补写。
选择另一本或新建时，未保存修改会提示确认；关闭标签页也会触发浏览器的未保存提示。

## 内容和来源

候选题目来自 `extraction_drafts.example` 的结构化原题，只查询当前课程中已完成识别、
已入库且关联知识仍有效的例题和习题。不把普通知识点当作习题，也不执行新的模型调用。
筛选结果分页显示，勾选状态和内容编辑跨筛选保留。

识别结果可能有误，加入前应核对原页；页面与题目识别提示会一起保存在本册和 PDF 中。
知识库正文已修订时，会提示这里仍为原始识别结果，提供最新知识正文入口；
加入新题时核对读取到的知识版本，版本变化返回 409，要求重新载入核对。

本册保存独立内容快照。修改本册不回写知识库，知识库后续修订也不会静默替换本册。
删除原课件后，本册仍可编辑和打印，保留原课件名与页码；删除本册不删除知识或原题。
删除课程时，数据库外键级联删除该课程的所有做题本。

## 章节与标签整理

优先读取 PDF 书签目录，再检查明确的一级章节标题；无法确定时，账号 LLM 根据逐页摘要识别边界。
章节管理位于课件详情 `/courses/{id}/documents/{doc}`；课程资料列表提供“课件详情与章节”入口。
做题本来源列表的“管理章节”在新标签页打开，避免离开当前未保存题本；返回题本时刷新章节列表。
“章节与原题整理”保留自动识别、手动添加、修改名称和页码等能力，不再占据做题本主页。新课件提取后仍默认自动提交整理任务。
扫描页可使用已有页面转录。没有可靠边界时明确显示“未分章资料”，保留手动编辑入口。
章节范围要求按页码排序、不重叠、不越界。知识点通过来源页码关联章节，原题按提取页关联，修改范围立即更新关联。
“添加章节”只创建名称和页码范围，不新增题目。章节划分可选，不分章也可以整理整门课程或按课件、页码选题。

任务通过 Redis 的 `documents` 队列运行，继续使用 Windows SpawnWorker。
任务只携带文档编号、运行编号和是否保留章节，不携带模型密钥。后台使用账号模型。
每次写回核对运行编号，手动保存章节会取消旧运行；删除课程或课件后，旧任务不能重新创建数据。
提取完成后的自动任务保留已有章节；用户主动重新识别会替换当前章节，保留已确认裁片。
任务可查看进度、失败原因并重试。部分页失败保留成功结果并显示提示。

有原题的页面会标注题型、估计难度和考查知识点，并在视觉模型可用时建议裁切区域。
纯文字模型仍能标注标签，区域保持空值；没有模型时不生成假标签或坐标。
自动区域始终是待核对建议，不直接用于打印。题型、难度和知识点标签可以手动修正。
`DOCUMENT_AUTO_ORGANIZE=false` 可关闭提取完成后的自动整理，不影响手动操作。

## 自动选题

使用顶部所选来源课件、章节与页码范围，支持总题数、题型配额和难度配额，也可输入自然语言要求。
来源或范围变化后旧预览失效，不能误用先前范围的结果。服务端在调用模型前验证课件归属、章节范围和页码；模型只接收所选课件的章节列表。
明确表单选项优先。选择“全部原题并去重”且不填写附加要求，或输入“所有题都要，但是把重复题去掉”等简单要求时，在本地收集范围内全部原题并去重，不调用模型，也不默认截取 10 题。
其它文字要求由账号 LLM 理解，再从候选原题编号中排序选择。去重后超过 100 题时明确要求按章节分册，不静默截断；结果显示候选数与去重数。
模型不能写入新题，服务端检查章节范围、题目编号、重复项及配额。
指定章节无法确定时要求明确选择，不擅自扩大到整门课程。

本地选题优先覆盖不同知识点和章节；同时指定题型、难度配额时检查组合是否可满足，避免先选一题导致后续配额无解。
文字题按归一化题干去重；图题保守保留，避免同题干不同题图被误合并。
候选最多 2000 题，模型精读按章节均衡取样最多 300 题；超过范围会要求缩小范围或显示取样提示。
难度为估计标签，不代表经过真实答题校准。未标注难度的题目不会当作指定难度填入。

结果显示实际题数、缺题数量、题型分布和考查知识点，不使用新题或范围外题目补齐。
自动结果先预览，打开后作为独立新草稿；当前有未保存修改时明确提示。

## 原题与题图裁片

框选坐标以原页左上为原点归一化到 0–1，与网页原页预览的旋转坐标系一致。
每题最多 12 个区域，均限定在同一份课件内；可跨多个页面，并按区域顺序打印。
完整原题框需要包含题干、选项、公式和必要题图；题图框只包含文字重排时需要的图表。
确认前必须核对并排除答案与解题步骤。区域可拖动重画，也可输入坐标。

确认后在本机通过 PyMuPDF 生成高分辨率 PNG 裁片（最高 3 倍渲染，最长边 3000 像素），
保留可见的原公式和图形外观，不将框外隐藏 PDF 文本或答案带入裁片。
这是图片保真打印，不是矢量无损导出。单题图片不超过 20 MB，做题本图片总量不超过 60 MB。

文字重排版使用可编辑 Markdown 和已确认题图；原题保真版使用已确认完整原题裁片。
修改题干文字不会改写保真裁片。缺少裁片时保真导出明确失败，不能静默略过题目。
做题本保存图片独立副本，后续修改源裁片或删除课件不会替换旧本册。

跨页裁片可手动追加；跨页题干和解析的自动合并、AI 新题生成仍待接入。

## 导出环境

PDF 在本机生成：Python 服务通过 Node.js 调用 `frontend/scripts/render-workbook.mjs`，
使用 Playwright、React Markdown、GFM、数学语法和 KaTeX 排版。
Windows 复用已安装的 Microsoft Edge；其它系统需安装 Playwright Chromium。
需要 Node.js 20+ 和 `frontend` 的 npm 依赖，Playwright 是运行依赖，不依赖测试包。
Python 环境依然由 uv 管理，无新增 Python 依赖。

导出不要求前端开发服务器运行。PDF 排版不调用模型，远程字体、网页图片和外部脚本均不参与生成。
KaTeX 字体从本机依赖内联载入，中文使用本机中文字体；Markdown 原始 HTML 被跳过，
浏览器禁止网络请求、禁用页面脚本。外部 Markdown 图片显示占位说明。
输出直接返回给当前账号，不生成公开文件链接，也不另存导出文件。题图与原题裁片通过账号、课程和做题本归属校验后读取。

每个后端进程最多同时渲染两份 PDF；单次渲染超时返回可重试错误。
依赖、浏览器缺失或渲染失败时返回明确错误，不返回模拟 PDF，已保存的内容仍然保留。

## 数据与接口

迁移 `0010` 新增 `workbooks`，保存课程归属、名称、版本、章节内容快照、打印设置及时间。
迁移 `0011` 新增 `document_structures`、`chapters`、`exercise_layouts`、`exercise_assets` 与 `workbook_assets`。
图片二进制延迟加载，不随题目列表返回，不写入模型任务参数。课程及课件删除通过外键清理对应数据，本册图片只随本册删除。
更新时锁定当前行并检查 `expected_version`，避免多标签页覆盖。导出要求指定已保存版本。
接口均先验证课程归属；新增题目还验证其课件、知识与当前课程一致，来源元数据由服务端提供。

| 方法与路径（均在 `/api` 下） | 用途 |
| --- | --- |
| `GET /courses/{id}/exercises` | 按课件、页码、类型和标题分页筛选原题 |
| `GET /courses/{id}/chapters` | 课程章节及关联题目、知识点数量 |
| `GET /documents/{doc}/structure` | 整理进度和章节列表 |
| `POST /documents/{doc}/structure` | 提交章节、标签与区域识别任务 |
| `PUT /documents/{doc}/chapters` | 校验版本后修改章节范围 |
| `GET /courses/{id}/exercises/{draft}/layout` | 读取区域建议与标签 |
| `PUT /courses/{id}/exercises/{draft}/layout` | 校验版本后保存、确认裁片 |
| `POST /courses/{id}/workbooks/assemble` | 按要求自动选取原题并返回草稿与缺题报告 |
| `GET /courses/{id}/workbooks` | 列出本课程做题本 |
| `POST /courses/{id}/workbooks` | 保存新做题本 |
| `GET /courses/{id}/workbooks/{book}` | 打开本册快照 |
| `PUT /courses/{id}/workbooks/{book}` | 校验版本后更新 |
| `PATCH /courses/{id}/workbooks/{book}/title` | 校验版本后仅更新名称 |
| `DELETE /courses/{id}/workbooks/{book}` | 删除本册 |
| `GET /courses/{id}/workbooks/{book}/pdf?version=N` | 导出指定已保存版本 |

`exercises` 与 `assemble` 支持 `document_ids`、`chapter_ids`、`page_from`、`page_to`，省略来源保持全课程兼容；明确的空来源不能用于自动整理。GET 的编号列表使用重复查询参数。

测试覆盖筛选、分页、跨账号和跨课程隔离、快照保留、修改冲突、来源校验、级联删除，
并实际启动浏览器生成 PDF 检查中文、公式和答案分离。浏览器测试检查选题、分组、排序、编辑、
保存、下载及手机布局，使用固定题目和隔离测试库，不读取用户课件。
